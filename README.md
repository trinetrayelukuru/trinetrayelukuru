## About Me

I'm an **AI Engineer** and **Full Stack Developer** from **VIT Vellore**, building systems where **LLMs**, **agentic AI**, and **IoT** work together in production.

I design intelligent pipelines with **LangGraph**, **CrewAI**, and **OpenAI APIs** — from document summarization to multi-agent customer support automation.
